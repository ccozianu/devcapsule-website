# Website requirements

The initial contract is DevCapsule's
[2026-09-16 website work order](https://github.com/ccozianu/devcapsule/blob/main/engineering-docs/work-orders/2026-09-16-website-autonomy.md).

- Preserve the landing-page substance and visible project-health information.
- Publish user documentation with natural internal links and meaningful navigation.
- Present the development blog; send other engineering/developer material to GitHub.
- Keep current release behavior distinct from drafts, history, and intended V1.
- Provide comfortable reading, mobile layouts, keyboard navigation and code examples.
- Keep content authoritative in DevCapsule and presentation authoritative here.
- Support both parent and standalone preview, with identifiable source revisions.
- Provide repeatable content and styling updates without editing the other layer.
- Supply an independent DevCapsule configuration and resumable project instructions.
- Stop at a reviewable result. Production publication requires owner acceptance.

Validation evidence and pending acceptance belong in [CURRENT-STATUS.md](CURRENT-STATUS.md).
